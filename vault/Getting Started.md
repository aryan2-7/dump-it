# Getting Started

## Open a vault

1. Click **Open Vault Folder** in the sidebar
2. Select any folder containing `.md` files
3. Try selecting this folder: the project's `vault/` directory

## Edit notes

- Click a note in the file tree to open it
- Type in the left pane — preview updates live on the right
- Changes auto-save after a short delay

## Wiki links

Link between notes with double brackets:

```
[[Welcome]]
[[Another Note|Custom label]]
```

Click a wiki link in the preview to jump to that note.

## Tips

- Folders appear in the sidebar tree
- Hidden files (starting with `.`) are ignored
- Your last vault path is remembered between sessions

See also: [[Welcome]]
